### Campus Companion — School Management Platform 🔒

_Private repository · access on request_

A live school platform with student, teacher, parent and principal panels: homework, timetables, exams, grades, attendance, student progress and incident reports, with RFID card attendance on ESP32 readers.

Originally built by my son **Yamen** for his own school. I led its productisation into this generic edition: architecture review, security hardening, the end-to-end test strategy, CI and architecture decision records.

- Role-based access enforced on the server, with parents linked only to their own children
- Live updates pushed to every open panel
- A web app and IoT devices sharing one API
- A phased product roadmap toward assessments, AI-assisted marking and learning analytics

`TypeScript` · `Node.js` · `SQLite / Turso` · `ESP32`
